# تیمزو اپ — پروژه اندروید

پروژهٔ منبع اپلیکیشن اندرویدی با رابط فارسیِ HTML که به‌صورت محلی از فایل `app/src/main/assets/index.html` اجرا می‌شود.

## ساخت APK خودکار در GitHub

1. محتویات ZIP را در یک مخزن GitHub قرار دهید.
2. پوشهٔ `.github/workflows/build.yml` را حفظ کنید و پروژه را به شاخهٔ `main` یا `master` پوش کنید.
3. در GitHub به **Actions** بروید و اجرای **Build Android APK** را باز کنید.
4. پس از موفقیت، از بخش **Artifacts** فایل `my-app-apk` را دانلود کنید؛ APK درون آن است.

همچنین می‌توانید پروژه را در Android Studio باز کرده و از **Build > Build APK(s)** استفاده کنید.

شناسهٔ اپ: `ir.timzo.myapp` — حداقل اندروید: API 21 — نسخهٔ هدف: API 34.

این ZIP شامل کد منبع و گردش‌کار ساخت خودکار است، نه APK از پیش ساخته‌شده. فایل APK پس از اجرای موفق GitHub Actions تولید می‌شود.
